Frequently asked questions

Is it really free?

Yes — bots run on always-free cloud servers, so basic hosting costs nothing.

Which bots can I host?

Any Telegram bot: Bot API token bots and custom Python/Node/MTProto projects. Websites can be hosted on the same server too.

Can I message all users at once?

Yes. Broadcast sends one message with an optional link button to every user of every hosted bot.
